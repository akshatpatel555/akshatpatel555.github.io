Parallel Monte Carlo Simulator

High-performance Monte Carlo simulation parallelized with OpenMP, with SIMD exploration and Rust port comparisons.

Problem

Monte Carlo methods are inherently parallelizable but realizing speedup requires careful thread management, avoiding race conditions on shared state, and understanding hardware limits like Amdahl's law.

Solution

CS 475 parallel programming project implementing Monte Carlo estimation in C++ with OpenMP. Benchmarked speedup curves across 1–N threads, explored SIMD vectorization for hot loops, and ported select algorithms to Rust to compare performance characteristics.

Key Engineering

  • OpenMP parallel for-loops with dynamic scheduling for load balance
  • Speedup and efficiency benchmarking across thread counts
  • SIMD vectorization experiments on random number generation paths
  • Rust port for memory-safety vs. raw performance tradeoff analysis
