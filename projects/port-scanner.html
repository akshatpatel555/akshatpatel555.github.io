Concurrent Port Scanner

Multi-threaded C++ port scanner comparing thread-based and async I/O concurrency models for network throughput.

Problem

Scanning many ports on a host is I/O-bound — sequential connections are slow. Parallelism can dramatically improve throughput, but the concurrency model matters for resource usage and scalability.

Solution

Built a port scanner in C++ using parallel socket connections via OpenMP threads. Compared thread-based concurrency against async I/O approaches and measured throughput gains across different port ranges and host configurations.

Key Engineering

  • Parallel TCP socket connections with configurable thread pool
  • Timeout handling for unresponsive ports
  • Throughput benchmarking: threads vs. sequential baseline
  • Comparison of thread-based vs. async I/O concurrency patterns
