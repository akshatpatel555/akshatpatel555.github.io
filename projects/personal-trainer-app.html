Full-Stack Mobile

Personal Trainer App

Senior capstone full-stack mobile fitness platform — Flutter front-end, FastAPI backend, MongoDB storage, and multi-factor authentication.

Problem

Personal trainers need a way to manage client workouts, track training sessions, and authenticate users securely across mobile devices — without relying on paper logs or generic fitness apps that don't fit trainer-specific workflows.

Solution

Built as part of the Byte Squad capstone team (CS 46x), the app pairs a Flutter mobile client with a FastAPI REST API and MongoDB. I led backend architecture: JWT-based auth, PyOTP two-factor authentication, QR code login flows, and REST endpoints for workout and session management. Coordinated Flutter integration across the team.

Key Engineering

  • FastAPI backend with Pydantic validation and structured error responses
  • JWT access tokens with OTP second factor and QR-based session pairing
  • MongoDB document storage for flexible workout and user schemas
  • Cross-team API contract design for Flutter front-end integration
  • Agile sprints with code review and iterative delivery across two semesters
