Full-Stack Mobile AI

AI-Powered Cross-Platform Fitness Tracker

Senior capstone — a cross-platform fitness app that builds, tracks, and recommends personalized workouts with OpenAI-driven generation and multi-factor mobile auth.

Problem

Fitness apps often give generic plans. Trainers and athletes need a secure, cross-platform system that can generate personalized workouts, track progress, and authenticate users without fragile password-only flows.

Solution

Led backend architecture for a Flutter (iOS/Android) client backed by a FastAPI REST API and MongoDB. Integrated the OpenAI API for AI-driven workout generation, and engineered multi-factor authentication combining JWT access tokens, PyOTP verification, and QR-code session pairing. Delivered on a 5-person Agile team across two semesters.

Key Engineering

  • FastAPI REST API with MongoDB storage for workouts, users, and recommendations
  • OpenAI API integration for personalized workout generation
  • JWT + PyOTP + QR-code session pairing for secure mobile login
  • Cross-team API contracts and Flutter front-end integration
  • Git/GitHub, sprint planning, and code review across a two-semester Agile delivery
