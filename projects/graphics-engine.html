Graphics

3D Graphics Rendering Engine

OpenGL-based 3D rendering projects including an interactive Solar System simulation with custom GLSL shaders, texture mapping, and keyframe animation.

Problem

Understanding real-time 3D rendering requires building the pipeline from scratch — vertex processing, shader programs, lighting models, texture mapping, and animation — not just using a game engine.

Solution

CS 381 coursework building progressively complex OpenGL scenes in C++. The capstone project is an interactive Solar System with orbiting planets, physically-based lighting, custom vertex/fragment shaders, texture-mapped surfaces, and camera controls.

Key Engineering

  • Custom GLSL vertex and fragment shaders for lighting and texturing
  • 3D transformation matrices — model, view, and projection pipelines
  • Texture loading and UV mapping on sphere and mesh geometry
  • Keyframe animation with interpolated orbital motion
  • Interactive camera with keyboard/mouse input handling
