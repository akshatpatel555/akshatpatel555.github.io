Database Management Web App

Relational database-backed web application with normalized schema design, complex SQL queries, and a full CRUD PHP front-end.

Problem

Web applications backed by relational data need careful schema design, normalization, and efficient queries — plus a usable interface for non-technical data entry.

Solution

CS 340 databases project — designed a normalized MySQL schema with proper foreign key relationships, wrote complex joins and stored procedures, and built a PHP/HTML/CSS front-end with full create, read, update, and delete operations.

Key Engineering

  • Schema normalization to 3NF with entity-relationship modeling
  • Complex multi-table joins and aggregate queries
  • Stored procedures for reusable database logic
  • Parameterized queries to prevent SQL injection
  • Full CRUD web interface with form validation
